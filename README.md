# Landing Page — HTML & CSS

Responsive landing page built from scratch using semantic HTML and modern CSS practices.  
This project focuses on **layout structure, responsive design, and reusable components**, following a workflow similar to a real-world frontend environment.

---

## 🔍 Overview

The goal of this project was to build a clean and scalable landing page while applying professional frontend patterns such as:

- Semantic HTML structure
- Mobile-first responsive layout
- Flexbox-based layouts
- Reusable UI components
- Clean and maintainable CSS architecture

Text content is simple and generic on purpose — the main focus is **code quality, layout, and responsiveness**.

---

## ✨ Features

- Semantic HTML5 (`header`, `main`, `section`, `footer`)
- Mobile-first responsive design
- Flexbox layouts for hero and services sections
- Reusable components (buttons, form groups)
- Consistent spacing and typography hierarchy
- Image-based hero section
- Clean and readable CSS structure

---

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, media queries, CSS variables)
- Git & GitHub

---

## 📱 Responsive Design

The layout adapts seamlessly across screen sizes:

- **Mobile:** stacked content for readability
- **Tablet / Desktop:** side-by-side layouts with controlled widths

---

## 🚀 What I Practiced in This Project

- Structuring HTML for scalability and accessibility
- Separating layout, spacing, and components
- Debugging and fixing real layout issues
- Working with Git using small, descriptive commits
- Thinking like a frontend developer in a team environment

---

## 📌 Notes

- Images and icons are used as placeholders.
- The project does not rely on frameworks or libraries.
- JavaScript is intentionally excluded to keep the focus on HTML & CSS fundamentals.
